# AI Voice Memos — rules
# One rule per line:  /skill-name : plain-language condition for when it should run
# Managed by the configurator; also editable by hand. Comment a line to disable.
#
# Each /skill-name must exist as a skill in ~/.claude/skills/<name>/SKILL.md.
# The condition is read by the router model, not by code — write it the way
# you'd explain it to a person. Copy this file to ~/.voice-memo-ai/rules.txt
# and replace these examples with your own skills.

/note : when the memo is a personal note, reminder, or thought to save for later
/wordcount : when the memo contains any spoken words (test skill — useful for verifying the pipeline end to end)
# /summarize : when the memo is longer than a minute and rambles — write a tight summary to a dated file
